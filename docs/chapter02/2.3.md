# 2.3 在2.2节中，我们实现了一个简化版的ELIZA聊天机器人。请在此基础上进行扩展实践
> 本版本修复原代码缺陷：支持缩写句式`I'm`、`what's my`；增加姓名黑名单，避免将职业/情绪误识别为姓名；解决自我介绍后查询记忆无法命中的问题。

## 2.3.1 为ELIZA添加3‑5条新的规则，使其能够处理更多样化的对话场景（如谈论工作、学习、爱好等）
### 新增规则功能说明
在原有ELIZA基于正则的`rules`规则字典中新增5组**模式‑响应模板**，覆盖工作、学习、爱好、情绪、个人目标场景：

|正则匹配模式|功能说明|
|---|---|
|`r'I work (as\|at) (.*)'`|匹配用户描述工作，支持`work as 职业`、`work at 单位`两种句式，双捕获组提取信息，询问工作感受|
|`r'I study (.*)'`|匹配用户讲述自己学习的科目，询问选择理由与学习体验|
|`r'My hobby is (.*)'`|匹配用户介绍个人爱好，询问爱好时长与感受|
|`r'I feel (happy\|sad\|angry\|lonely) about (.*)'`|捕获用户表达对事件的情绪，追问情绪产生的原因|
|`r'I want to (.*) in (.*)'`|捕获用户说出个人目标，追问计划与期望|

规则执行流程：
1. `re.search()`忽略大小写匹配用户输入文本；
2. 捕获括号分组中的用户内容；
3. 调用代词转换函数处理人称；
4. 在候选列表随机选一条模板，把捕获内容填充进`{0}/{1}`占位符输出。

## 2.3.2 实现一个简单的"上下文记忆"功能：让ELIZA能够记住用户在对话中提到的关键信息（如姓名、年龄、职业），并在后续对话中引用
### 代码模块独立功能说明
1. **全局记忆存储 `user_context = {}`**
    字典容器，持久保存本轮对话提取的用户信息，key包括`name`姓名、`age`年龄、`job`工作内容、`job_prep`介词。

2. **黑名单常量 `NOT_NAME_WORDS`**
    过滤词集合，防止把情绪词、职业名词错误识别为用户姓名，修复 `I am a teacher` 把teacher当成名字的bug。

3. `update_context(user_input)` 信息提取函数
    - 正则匹配多种自我介绍句式：`my name is XX` / `I am XX` / `I'm XX`；
    - 匹配`XX years old`提取年龄；
    - 匹配`work as / work at`提取职业；
    - 经过黑名单校验后，将有效信息写入全局记忆字典`user_context`。

4. `get_personalized_prefix()` 个性化前缀生成
    读取记忆字典，随机生成带有用户姓名/年龄/职业的句子片段；
    在30%概率下拼接在普通回复之前，实现对话过程主动引用用户信息。

5. **记忆查询逻辑（内嵌于`respond()`）**
    - 兼容问句：`what is my` / `what's my` / `do you remember`；
    - 用户询问自己的姓名、年龄、职业，直接读取记忆字典给出回答；
    - 如果还没有收集对应信息，则返回提示。

6. `swap_pronouns(phrase)`代词转换工具
    ELIZA原有核心逻辑，完成第一人称↔第二人称代词互换（`i`↔`you`、`my`↔`your`等）。

7. `respond(user_input)`总响应入口函数（执行顺序）
    ①调用`update_context()`，从最新输入更新记忆；
    ②判断用户是否在查询记忆，命中则直接返回记忆问答；
    ③遍历`rules`做正则模式匹配，完成代词转换与模板填充；
    ④随机概率拼接个性化记忆前缀；
    ⑤无匹配时使用兜底通配符规则，返回最终回复字符串。

8. **主聊天循环 `if __name__ == '__main__'`**
    控制台交互，接收用户输入；识别`bye/exit/quit`退出程序；处理空输入异常，调用`respond()`打印对话回复。

### 完整代码
```python
import random
import re

rules = {
    r'I need (.*)': [
        "Why do you need {0}?",
        "Would it really help you to get {0}?",
        "Are you sure you need {0}?"
    ],
    r'Why don\'t you (.*)\?': [
        "Do you really think I don't {0}?",
        "Perhaps eventually I will {0}.",
        "Do you really want me to {0}?"
    ],
    r'Why can\'t I (.*)\?': [
        "Do you think you should be able to {0}?",
        "If you could {0}, what would you do?",
        "I don't know -- why can't you {0}?"
    ],
    r'I am (.*)': [
        "Did you come to me because you are {0}?",
        "How long have you been {0}?",
        "How do you feel about being {0}?"
    ],
    r'.* mother .*': [
        "Tell me more about your mother.",
        "What was your relationship with your mother like?",
        "How do you feel about your mother?"
    ],
    r'.* father .*': [
        "Tell me more about your father.",
        "How did your father make you feel?",
        "What has your father taught you?"
    ],
    # 新增工作场景
    r'I work (as|at) (.*)': [
        "What do you like most about working {0} {1}?",
        "How long have you worked {0} {1}?",
        "Does working {0} {1} bring you a sense of fulfillment?"
    ],
    # 新增学习场景
    r'I study (.*)': [
        "Why did you choose to study {0}?",
        "What do you find most interesting about {0}?",
        "How do you feel when studying {0}?"
    ],
    # 新增爱好场景
    r'My hobby is (.*)': [
        "How long have you been interested in {0}?",
        "What do you enjoy most about {0}?",
        "How does {0} make you feel in daily life?"
    ],
    # 新增情绪场景
    r'I feel (happy|sad|angry|lonely) about (.*)': [
        "Why do you feel {0} about {1}?",
        "What made you start feeling {0} about {1}?",
        "How do you want to change how you feel {0} about {1}?"
    ],
    # 新增目标场景
    r'I want to (.*) in (.*)': [
        "What steps are you taking to {0} in {1}?",
        "Why is it important for you to {0} in {1}?",
        "How would your life change if you {0} in {1}?"
    ],
    r'.*': [
        "Please tell me more.",
        "Let's change focus a bit... Tell me about your family.",
        "Can you elaborate on that?"
    ]
}

pronoun_swap = {
    "i": "you", "you": "i", "me": "you", "my": "your",
    "am": "are", "are": "am", "was": "were", "i'd": "you would",
    "i've": "you have", "i'll": "you will", "yours": "mine",
    "mine": "yours"
}

def swap_pronouns(phrase):
    words = phrase.lower().split()
    swapped_words = [pronoun_swap.get(word, word) for word in words]
    return " ".join(swapped_words)

# 全局记忆
user_context = {}
# 姓名黑名单，防止把职业、情绪识别为名字
NOT_NAME_WORDS = {'happy', 'sad', 'angry', 'tired', 'old', 'young',
                  'a', 'an', 'the', 'student', 'teacher', 'doctor',
                  'worker', 'programmer', 'designer', 'engineer'}

def update_context(user_input):
    input_lower = user_input.lower().strip()
    # 提取姓名，支持 I'm / I am / my name is
    name_patterns = [
        r'my name is ([a-zA-Z\s\-]{1,20})',
        r'i\'m ([a-zA-Z\s\-]{1,20})',
        r'i am ([a-zA-Z\s\-]{1,20})'
    ]
    for pattern in name_patterns:
        match = re.search(pattern, input_lower, re.IGNORECASE)
        if match:
            name_candidate = match.group(1).strip(' .,!?')
            name_words = set(name_candidate.lower().split())
            if not name_words & NOT_NAME_WORDS:
                user_context['name'] = name_candidate
            break
    # 提取年龄
    age_match = re.search(r'(\d{1,2}) years? old', input_lower, re.IGNORECASE)
    if age_match:
        user_context['age'] = age_match.group(1)
    # 提取职业
    job_match = re.search(r'work (as|at) ([a-zA-Z\s]{1,30})', input_lower, re.IGNORECASE)
    if job_match:
        user_context['job_prep'] = job_match.group(1)
        user_context['job'] = job_match.group(2).strip(' .,!?')

def get_personalized_prefix():
    if not user_context:
        return ""
    prefixes = []
    if 'name' in user_context:
        name = user_context['name']
        prefixes.extend([
            f"By the way {name}, ",
            f"{name}, I was thinking about what you said earlier: ",
            f"Speaking of that {name}, "
        ])
    if 'age' in user_context and 'job' in user_context:
        prefixes.append(f"As a {user_context['age']}-year-old {user_context['job']}, ")
    elif 'age' in user_context:
        prefixes.append(f"At {user_context['age']} years old, ")
    elif 'job' in user_context:
        prefixes.append(f"As a {user_context['job']}, ")
    return random.choice(prefixes) if prefixes else ""

def respond(user_input):
    update_context(user_input)
    input_lower = user_input.lower()
    # 判断是否查询记忆，支持 what's 缩写
    is_query_memory = ('what is my' in input_lower
                       or "what's my" in input_lower
                       or 'do you remember' in input_lower)
    if is_query_memory:
        if 'name' in input_lower and 'name' in user_context:
            return f"Your name is {user_context['name']} – I remember that!"
        elif 'age' in input_lower and 'age' in user_context:
            return f"You told me you are {user_context['age']} years old."
        elif ('job' in input_lower or 'work' in input_lower) and 'job' in user_context:
            prep = user_context.get('job_prep', 'as')
            return f"You work {prep} {user_context['job']}, right?"
        else:
            return "I haven't learned that about you yet – tell me more!"

    base_response = ""
    for pattern, responses in rules.items():
        match = re.search(pattern, user_input, re.IGNORECASE)
        if match:
            captured_groups = match.groups()
            swapped_groups = [swap_pronouns(g) for g in captured_groups] if captured_groups else []
            if swapped_groups:
                base_response = random.choice(responses).format(*swapped_groups)
            else:
                base_response = random.choice(responses)
            break
    if not base_response:
        base_response = random.choice(rules[r'.*'])

    # 30%概率拼接个性化前缀
    if random.random() < 0.3:
        pre = get_personalized_prefix()
        if pre:
            base_response = pre + base_response.lower()
    return base_response

if __name__ == '__main__':
    print("Therapist: Hello! How can I help you today? (Type 'bye'/'exit'/'quit' to end)")
    while True:
        user_input = input("You: ")
        if user_input.lower() in ["bye", "exit", "quit"]:
            print("Therapist: Goodbye! It was nice talking to you.")
            break
        if not user_input.strip():
            print("Therapist: I'm listening – please share something with me.")
            continue
        print(f"Therapist: {respond(user_input)}")
```

|维度|扩展ELIZA（规则式）|ChatGPT（大语言模型）|
|----|----|----|
|知识表示|显式硬编码正则规则、响应模板；知识全部写死代码中|分布式隐式知识，存储于神经网络海量参数|

|生成方式|从预定义模板字符串做替换，输出内容有限，无创造能力|基于概率逐Token生成，产出全新符合语义的文本|
|泛化能力|只能匹配写好的正则模式，句式改写就失效|具备零样本、少样本泛化，同义不同表述可以识别语义|

## 2.3.4 为什么基于规则的方法在处理开放域对话时会遇到"组合爆炸"问题并且难以扩展维护？能否使用数学的方法来说明？
自然语言词汇可以自由组合，想要覆盖人类多种多样表达方式，如果依靠手写规则，**规则数量随场景维度呈指数增长，也就是组合爆炸**。

数学简单建模：
假设：常用词汇集合大小 V=5000，平均句子长度 L=15。
理论全部词汇组合数：
V^L = 5000^15 = 3.1 * 10^53

即使只筛选现实中有意义的人类表达，约 10^12 种；假设一条正则规则可以覆盖100种不同说法，则需要手写规则数目：
N = 10^12 / 100 = 10^10
数量已经远远超出人工编写、调试的能力。

额外带来维护困难：
1. 新增一个对话维度（情绪、身份、场景），总规则数会成倍上涨；
2. 大量正则之间会出现匹配冲突，需要手动调整优先级；
3. 口语变体、同义改写、新的网络表达，都必须新增规则，无法自动适配。

>本质：规则系统需要人为枚举输入模式；而大模型通过统计学习，直接学习语言内在模式，不需要枚举全部输入。
