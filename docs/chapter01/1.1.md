# 1.1 请分析以下四个 `case` 中的**主体**是否属于智能体，如果是，那么属于哪种类型的智能体（可以从多个分类维度进行分析），并说明理由：

`case A`：**一台符合冯·诺依曼结构的超级计算机**，拥有高达每秒 2EFlop 的峰值算力
`case B`：**特斯拉自动驾驶系统**在高速公路上行驶时，突然检测到前方有障碍物，需要在毫秒级做出刹车或变道决策
`case C`：**AlphaGo**在与人类棋手对弈时，需要评估当前局面并规划未来数十步的最优策略
`case D`：**ChatGPT 扮演的智能客服**在处理用户投诉时，需要查询订单信息、分析问题原因、提供解决方案并安抚用户情绪

# Answer

`case A`：不属于智能体.理由: 这是硬件概念, 智能体建立在软件层面上. 
#### 四个基本要素
- 自主性: 不会决策.
- 传感器: 缺乏外界感知.

`case B`：反应式智能体. 
#### 四个基本要素
- 自主性: 自行决策刹车或变道.
- 执行器: 刹车或变道.
- 环境: 前方突现障碍物.
- 传感器: 激光雷达 摄像头等.

`case C`：规划式智能体. 
#### 四个基本要素
- 自主性: 规划数十步下棋策略.
- 执行器: 落子或悔棋.
- 环境: 对弈时, 棋盘局势动态变化.
- 传感器: 摄像头.

`case D`：混合式智能体. 
#### 四个基本要素
- 自主性: 分析问题原因、思考解决方案.
- 执行器: 查询订单信息、提供解决方案并安抚用户情绪.
- 环境: 用户投诉.
- 传感器: 接收用户反馈的数据流的接口.
