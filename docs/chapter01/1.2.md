# 1.2  假设你需要为一个"智能健身教练"设计任务环境。这个智能体能够：

- 通过可穿戴设备监测用户的心率、运动强度等生理数据
- 根据用户的健身目标（减脂/增肌/提升耐力）动态调整训练计划
- 在用户运动过程中提供实时语音指导和动作纠正
- 评估训练效果并给出饮食建议

请使用 PEAS 模型完整描述这个智能体的任务环境，并分析该环境具有哪些特性（如部分可观察、随机性、动态性等）。

# Answer

`Performance(性能度量)`:
1. 健康指标的提升水平.
2. 用户体验和训练计划的完成度.
3. 用户安全,避免受伤.
4. 健身目标进度.

`Environment(环境)`:
1. 用户的生理数据, 来自可穿戴设备获取.
2. 所在周边环境, 如场地等.

`Actuators(执行器)`:
1. 训练计划的规划和模拟, 以及动态调整优化.
2. 语音合成和播放.
3. 可视化交互界面, 如训练计划, 动作示范纠正, 和用户打卡.
4. 饮食建议, 改善营养状况.
5. 通信模块, 可用于急救电话和联系家属.

`Sensor(传感器)`:
1. 可穿戴设备感知数据.
2. 用户主动输入各种信息和指令.
