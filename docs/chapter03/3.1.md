# 3.1 自然语言处理中，语言模型经历了从统计到神经网络的模型演进。

## 3.1.1 请使用本章提供的迷你语料库（datawhale agent learns, datawhale agent works），计算句子 agent works 在 Bigram 模型下的概率.

迷你语料库：

- 句子1：`datawhale agent learns`
- 句子2：`datawhale agent works`

语料全部词序列：`datawhale`、`agent`、`learns`、`datawhale`、`agent`、`works`，总词数=6。

Bigram（二元语法）联合概率公式： P(w_1 w_2 )= P(w_1) *  P(w_2|w_1)

1. 计算P(agent)：`agent`在全部语料出现2次

P(agent) = count(agent) / 总词数 = 2/6 ≈ 0.333

1. 条件概率 P(works | agent)：统计二元组`agent works`出现次数，`agent`作为前序词共出现2次

P(works | agent) = count(agent works) / count(agent) = 1 / 2 = 0.5

1. 句子`agent works`的Bigram概率：
  (agent works) = P(agent) * P(works | agent)  = 2/6 * 1/2 = 1/6 ≈ 0.167



## 3.1.2 N‑gram 模型的核心假设是马尔可夫假设。请解释这个假设的含义，以及 N‑gram 模型存在哪些根本性局限？



### 马尔可夫假设

N‑gram的核心马尔可夫假设：**当前词语的出现概率，只取决于它前面最近的 n-1 个词，更早的上下文信息全部忽略，不对当前词预测产生作用**。

数学形式：
P(w_i | w_1,w_2,...,w_{i-1}) ≈ P(w_i | w_{i-n+1}, ... ,w_{i-1})

- Bigram(n=2)：仅看前面1个词；
- Trigram(n=3)：仅看前面2个词。



### N‑gram模型的根本性局限

1. **数据稀疏性**：大量词语组合不会出现在训练语料中，统计计数为0，对应条件概率为0；平滑技术只能缓解稀疏，无法从根源解决。
2. **固定有限上下文窗口**：最多只能利用前 n-1 个词，无法建模远距离词语依赖；增大窗口n会进一步加剧稀疏。
3. **离散符号建模**：直接使用离散词符号，不能表达词语之间的语义相似性。
4. **泛化能力差**，对于训练集从未见过的词组合预测效果很差。



## 3.1.3 神经网络语言模型（RNN/LSTM）和 Transformer 分别是如何克服 N‑gram 模型局限的？它们各自的优势是什么？

N‑gram的缺陷根源是离散统计计数、固定短上下文窗口、严重的数据稀疏。两类神经网络模型分别从词表示、序列建模机制进行改进。

### RNN / LSTM（循环神经网络语言模型）



#### 如何克服N‑gram局限

1. 引入**词嵌入（Word Embedding）**：将离散单词映射到低维连续向量空间，可以表达词语语义相似度，摆脱纯统计计数，大幅缓解数据稀疏，对未见过的词组合拥有泛化能力。
2. RNN循环结构理论可以读取全部上文，不受N‑gram固定窗口限制；基础RNN存在梯度消失问题难以捕捉长距离依赖；**LSTM引入细胞状态（Cell State）与遗忘门、输入门、输出门的门控机制**，可以将关键历史信息长期保存，有效学习长距离依赖。



#### RNN/LSTM优势

1. 天然适配时序顺序，建模序列先后关系；
2. 增量式处理序列，内存开销可控；
3. 依靠词向量获得语义泛化，不再完全依赖训练集词对的出现次数。

> 短板：训练时必须按时间步串行计算，无法并行，训练速度慢。



### Transformer模型



#### 如何克服N‑gram局限

1. 同样使用词嵌入表征词语，搭配位置编码补充序列顺序信息，脱离离散统计计数，缓解稀疏问题。
2. 自注意力（Self‑Attention）机制：序列任意两个位置的单词可以直接计算依赖关系，不受词与词之间距离限制，彻底打破N‑gram固定上下文窗口约束。
3. 舍弃循环迭代结构，输入序列可以实现**全并行计算**，极大提升训练效率。



#### Transformer优势

1. 依靠自注意力直接建模全局长距离依赖，建模能力强于LSTM；
2. 训练阶段可以并行运算，训练速度显著优于循环网络；
3. 多头注意力可以从多种语义角度同时捕捉词语关联。

> 短板：注意力计算复杂度随序列长度呈平方级增长，长输入会带来很高算力开销。
